Static web pages feel dead. Motion creates micro-dopamine triggers as users scroll, giving the impression of an expensive native desktop application.

  • • Smooth Scroll Reveals: Section headers slide up 20px on entry.

VOL I · GITHUB & THE HANDOFF

08c. GitHub for Absolute Beginners

Git is a time machine for your code. GitHub is the cloud where that time machine lives. A Repository is your project folder. A Commit saves your changes. Push uploads them, and Pull downloads them. Clone copies a repository to your local machine.

TRACK A: GitHub Desktop (GUI)
  1. 1. Install & Sign in to GitHub Desktop.
  2. 2. Click "Clone Repository" → select the one Lovable created.
  3. 3. Choose a local folder on your computer.
  4. 4. Open that local folder in Antigravity.
  5. 5. To save changes: Write a summary in the bottom left, click "Commit", then "Push origin".
TRACK B: Terminal / CLI
  1. `git clone [URL]` (Download repo)
  2. `git add .` (Stage all changes)
  3. `git commit -m "update hero"` (Save)
  4. `git push origin main` (Upload)
  5. `git pull` (Download latest)
🚨 ABSOLUTE RULE: NEVER COMMIT SECRETS!

Never push `.env`, `.env.local`, API keys, or private database credentials to GitHub. Always use a `.gitignore` file.

AIWEBDEV PROMPT 1.13 GITHUB PREPARATION AUDIT (QA AUDITOR)
COPY THIS INTO ANTIGRAVITY: Prepare this repository safely for GitHub. Inspect the `.gitignore` file, check for any hardcoded secret files, generated build artifacts, or environment variables. Ensure no API keys will be leaked before I commit and push.

21. Localhost vs Production

Localhost is your laptop. When you run npm run dev, you create a tiny temporary server that only you can see. Production is the real world. Your code must be packaged (built), sent to a host, and connected to real databases and domains.

THE MENTAL MODEL
Browser (User)
↓
Frontend (Vercel)
↓
Backend/API (Render/Vercel)
↓
Database (Supabase)
🔥 CRITICAL MISCONCEPTION:

Vercel, Render, and Supabase are NOT interchangeable. Vercel is optimized for Frontend/React. Render is great for heavy Backends (like Python/FastAPI). Supabase is your Database. Don't try to host a Postgres database directly on Vercel.

22. Environment Variables From Zero

Your application needs to know where the Supabase database is. But if you hardcode the database URL and passwords directly into your source code, anyone can see them on GitHub. Environment variables allow you to configure secrets outside the code.

SERVER ONLY (SECRET)
  • SUPABASE_SERVICE_ROLE_KEY
  • DATABASE_URL
  • OPENAI_API_KEY

Never expose these to the browser.

SAFE FOR BROWSER
  • NEXT_PUBLIC_SUPABASE_URL
  • NEXT_PUBLIC_SUPABASE_ANON_KEY

The prefix NEXT_PUBLIC_ makes it visible.

Locally, we store these in a file called .env.local. We add this file to .gitignore so it never goes to GitHub. In production, we type these directly into Vercel's dashboard.

32. GoDaddy → Vercel Workflow
